## 为什么重构

旧15秒技术样片具有新动画源码、连续动作、源代码复现证据，但用户完整观看后指出人物不像正常人、15秒无法获取有效信息，**用户观看验收已否决**（见 `episodes/EP01/reviews/USER_ACCEPTANCE_R01.md`）。因此不能继续把“脚底触地、代码连续、粒子正确运动”当作最终观众效果。

## 本版创作核心

- **观众在一次观看后应能复述**：吃饭后葡萄糖会进入血液；走路使肌肉活动；肌肉活动可以促进葡萄糖摄取；短期血糖效果不代表寿命保证。
- **主角是一个看起来正常、动作可信的人**，不是用来测试关节的线条模型。
- **重点镜头语言是“尺度穿越”**：人物全景 → 明确部位（小腿）→ 局部剖面 → 细胞层面的真实状态变化 → 同路径退出 → 人物全景；必须保留空间锚点与对象身份，不能仅放大静态图。
- **原始 Sketchbook 源码为视觉引擎，不是现成画面素材**。保留统一手绘质感，但人物、美术和叙事必须为本集设计。
- 短视频需要可听懂、可看懂，不以研究论文的术语密度和 UI 标签数量来证明专业。
- 保留证据边界：短期餐后血糖的研究不能证明“走几步一定长寿”。
