# EP01 正式导演方案 v3.0｜以观众理解和多尺度镜头为中心（待独立审核）

> **CREATOR DRAFT / NOT APPROVED。** 唯一脚本：`SCRIPT_V2.md`。主风格沿用用户已选定的 Sketchbook 源码画风，但**旧15秒的抽象小人外形不再沿用**。人物新设计、内容联动与真实观感均未获得放行。9:16，建议约100–110秒，正式成片严格<120秒，全部时间按自然中文旁白校准。

## 一、导演观点与观众情绪

这不是“用显微镜解释一篇论文”，而是一趟**跟着真实的人走进身体又回到生活**的视觉旅程。

- 开头：一句夸张老话引出质疑，“真能活到九十九？”
- 第一个惊喜：原来刚吃过的饭，会在身体里变成可利用的葡萄糖。
- 第二个惊喜（核心镜头）：跟随一个真实可辨的人走路，镜头进入腿部，看见另一种尺度下的活动。
- 科学解释：不是“一踩地就吸一颗糖”，而是活动中的肌肉持续参与葡萄糖摄取。
- 第三个认知转折：短期研究的方向有支持，但“九十九岁”没有被证明。
- 结尾：从细胞退出回到人，留下温和、具体、不过度承诺的生活含义。

### 观众一次看完应该记住的唯一主句

**“饭后走路时，肌肉在活动，也能帮助身体利用血液中的葡萄糖；但不能因此断言长寿。”**

所有精美镜头必须为这句话服务，不能为了显示程序能力增加无意义粒子、转场或概念名词。

## 二、人物必须先成立

详见 `CHARACTER_AND_CAMERA.md`。全片必须使用**一个身份稳定的正常人**：有头颈肩、胸腹、骨盆、上臂前臂、大小腿、踝与完整脚掌；衣服可简单，但身体连接和重心符合普通人直觉。Sketchbook 是绘画质感，不等于可以把人物画成头、长条躯干、两根脱节的线腿。

完整正片不得先做8场再检查人物。镜头01与03/07是人物一致性和表演可读的关键位置。真实走路动作须为讲故事服务，并不要求每个关节都做拟真3D。

## 三、七幕叙事与可执行镜头

> 时间码是创作预算，不是精确配音锁定。推荐总长约106秒：01 00–13、02 13–24、03 24–36、04 36–53、05 53–67、06 67–89、07 89–106。允许为正常中文朗读、关键结构阅读和自然节奏调节，最终必须<120秒。

### 01｜00:00–00:13｜老话落在一个真实的人身上

- **口播 SCRIPT 01**：“饭后走一走……”至“真实的身体变化”。
- **全景画面**：日常餐桌旁，一个正常比例的成年人放下筷子、稍停、从椅子上站起。一只手整理衣角，脚迈出一小步；角色具有稳定肩、腰、骨盆和双脚。
- **提问的视觉钩子**：随人物起身，手写“活到九十九？”短暂出现在背景纸页边缘；“九十九”被铅笔轻轻圈出并出现问号，**不做年龄计数器或寿命提升图表**。
- **观众应该知道**：这是一条关于饭后走路是否有道理的视频；人物从此成为持续跟踪对象。
- **相机**：中景自然后退一点，让起身全过程完整入画。不要用高速推拉替代角色表演。
- **转场**：视线跟随人物放下的碗筷，餐桌和食物还在同一空间，下一幕顺势把焦点交给食物。

### 02｜00:13–00:24｜从饭进入血液，但先经过消化

- **口播 SCRIPT 02**。
- **动作链**：同桌上一碗淀粉类食物被铅笔圈起 → 画面从现实餐盘转成**标明“消化过程示意”**的手绘剖面 → 淀粉链逐节分开形成葡萄糖符号 → 进入肠道吸收示意 → 葡萄糖进入一段血管。
- **不展示的内容**：没有“整颗米饭直接钻进血管”，也不把肠道和腿部肌肉画成同一个部位。
- **画面重点**：只有“消化后产生葡萄糖”和“进入血液”两个步骤。文字只写“消化”“吸收入血”，其它靠动作展示。
- **相机**：从碗局部过渡到独立的身体消化示意页，给观众明确的尺度/场景切换标记；此处不需要再模仿主场戏的完整极端变焦。
- **转场**：进入血管后只留一枚可识别的黄色葡萄糖符号，镜头跟随它片刻；叠回现实中人物脚步声音，引向走路。

### 03｜00:24–00:36｜回到整个人，肌肉真的动起来

- **口播 SCRIPT 03**。
- **动作链**：人物从餐桌走向开阔路径，走路至少有几个清楚的支撑与摆动交替；可见脚掌落地、骨盆移动、上身和摆臂的自然协调；衣服在动作中保持稳定造型。
- **视觉信息**：从普通步行的外观中，观众能看到小腿/大腿随步态略有收放，而非一个静态人物被摄像机拖着移动。
- **相机**：先中全景，再从同一侧的连续跟拍缓慢靠近**右腿的小腿区域**。画面外部空间仍可辨，让观众始终知道在看同一个人。
- **转场动作**：右腿局部出现短暂柔和的手绘轮廓高亮（区域提示），形成下面放大的**唯一空间锚点**。不要突然换成另一个图形。

### 04｜00:36–00:53｜本集核心：镜头穿越尺度，看见肌肉里的变化

- **口播 SCRIPT 04**。
- **多尺度镜头必须按顺序发生**：
  1. 在右小腿的同一个世界坐标上慢慢收紧构图，鞋和膝盖先仍可辨；
  2. 选定区域出现**与腿部轮廓绑定的可视化剖面窗口**；表皮/肌肉束作为抽象结构开始可见；
  3. 随尺度提高，旧的外部人物线条渐弱，但**局部轮廓始终与新的剖面位置匹配**；
  4. 微观层次逐步产生真实新细节：一段毛细血管、组织间隙、肌肉细胞边界和可见肌纤维；
  5. 一枚高亮葡萄糖从毛细血管内部出发，先越过血管壁，再经过组织间隙，最后经过肌细胞膜上的转运示意进入细胞。
- **重要科学限制**：两个不同屏障必须是不同的对象；不能误把血管壁当细胞膜；肌肉收缩不与每颗粒子通过严格一一同步，不能暗示即时一脚降糖。
- **相机语言**：不是放大一张腿的 PNG。随倍率变化会显露新的解剖层次和运行过程。一个连续焦点移动让观众认出“刚才那个人→刚才那条腿→腿内肌肉”。
- **信息设计**：放大镜头仅依次出现必要标签“血液 / 组织间隙 / 肌细胞”，可在当前关键边界上短暂出现更精确的小标签；不要同时铺满五六种术语。
- **转场**：最后一颗粒子进入肌细胞，镜头停留一小段观察时间；肌肉细胞的规律形变继续，给“活动中的肌肉”提供可见上下文。

### 05｜00:53–00:67｜看到机制后，沿原路径退回人身上

- **口播 SCRIPT 05**。
- **主体继续动作**：肌肉收缩与放松贯穿葡萄糖进入的示意，过程保持为示意而非逐秒生理实况。
- **反向镜头**：肌细胞图 → 肌肉束剖面 → 右小腿的实际轮廓 → 恢复人物全身/中景；**沿同一相机锚点反向推进，不硬切至无关人物**。镜头回来后人物仍然在步行，不换服装、左右腿身份或背景方向。
- **重申因果**：仅用短文本“肌肉活动 ↔ 葡萄糖摄取”辅助；“≠ 一步立刻降糖”可用温和的视觉纠偏处理，不要让警告文本成为画面主角。
- **必须验收**：观众在回缩后能自然说“刚才看到的就是这个人腿里的过程”。若无法认出位置，尺度穿越失败。

### 06｜00:67–00:89｜研究不是魔法保证：一个有证据的方向

- **口播 SCRIPT 06**。
- **视觉构成**：从人物脚步留在纸页的痕迹切换到“研究发现”单页。8张小便签分批进入画面，聚成一份“8项短期试验”的总览。先呈现“饭后不运动”和“饭后运动”两种条件，再以不同的动作剪影表示两种状态，最后写出**唯一结论**：“餐后血糖波动：整体较小”。
- **不得伪造研究**：8张便签不填虚构数值、效果或方向；不画未经来源支持的个体血糖曲线；不假装研究全部只是散步。
- **屏幕信息的节奏**：每次只突出一个信息点——先“多项研究”、再“条件比较”、最后“总体方向”。将其余元素退为背景，给结论必要的阅读停顿。
- **科学限定**：文献有高偏倚风险，且纳入参与者和运动方式不同。旁白明确“效果因人而异”；必要文字标注“短期研究汇总示意，非个人血糖记录”，不以模糊小字藏限制。
- **转场**：研究页折回到道路旁，作为人物继续行动的纸面元素。视觉不要将“血糖改善”魔法变形成“寿命延长”。

### 07｜00:89–00:106｜回到同一个人，观众带走一件事

- **口播 SCRIPT 07**。
- **画面**：相机重新回到开场那个人的步行中景，同一衣服、体型、鞋和步行方向。背景保留开场餐桌与路径的场景关系；人物继续走，最后镜头轻微拉远，日常环境展开。
- **结论传达**：在“九十九”字样旁出现短暂的“不是保证”；随后字退到背景，只留下“适合自己，规律活动”的简短行动提示。
- **最后记忆点**：人的一小步与屏幕里曾看到的肌肉活动形成呼应，但不再进入微观剖面，也不重复第三次长变焦。
- **结束状态**：人物离开画面继续走，而非突然变成定格海报。画面可在最后约0.5–1秒自然停住作为收尾，不硬拖时间。

## 四、三条硬性的导演红线

1. **人不像正常人，直接判视觉方案未达到用户要求。** 不能因为关节测试正确就算人物设计合格。
2. **观众首次看不懂，不能靠开发者解释补课。** 如果脱离审核文档就不能理解“为什么镜头进入腿部”“粒子为何移动”，则信息主线失败。
3. **多尺度镜头失去空间联系，等同于失败的内容表达。** 缩放不能只是两张无关绘图做淡入淡出；镜头必须标定同一部位并在退出时回归同一人物。
