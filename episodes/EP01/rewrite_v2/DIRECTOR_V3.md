## 0. 这支片子的真正主角

**不是一双腿，也不是一颗黄色点。真正的主角是一个人，以及吃饭后、走路时身体里几个系统如何协同工作。**

观众从头到尾应认出同一人。在他/她体内，画面先呈现消化与吸收，再看血液循环，然后以“运动中的全身骨骼肌群”为背景，进入**一个代表性活动肌群的细胞层次**，完成后沿原路线缩回全身，最后以“研究能说明什么”与生活建议收尾。

应实现两种不同的局部放大：
- **局部注意力放大：** 在人体整体视图上圈定器官/部位，摄像机推进到具体变化；重点结束后再缩回人物/全身透视。
- **多尺度结构揭示：** 不是简单放大同一张图。镜头每深入一层，允许产生更细的结构和状态变化：器官表面→组织→血管→细胞→膜转运。各层既有可识别空间锚点，又有明确“原理示意”。

不得在整片中反复玩无意义的大幅推拉造成眩晕；**微观主场**集中在镜头05，前后的缩放服务于定位与回归。

## 2. 逐镜头执行剧本

### 01｜0–12秒｜人物在餐桌旁：从长寿夸张中提出问题

**首帧：** 真实可辨的成人坐于餐桌，筷子轻放到碗边。一个三维感来自简洁光影/比例而非写实贴图的 Sketchbook 手绘角色，衣服、肩、腰、骨盆、双臂和鞋底完整。

**连续事件：** 放筷 → 站起 → 身体重心调整 → 一步迈出；桌面留下“饭后走一走”，人物走到画面旁时“九十九？”出现一个由铅笔画出的问号。

**镜头：** 中景跟人，轻微推近面部疑问表情，再回到人物完整站姿；避免先出现片名静态海报。

**信息出口：** “我们不是在讨论寿命保证，而是想知道身体发生了什么。”这一点通过疑问而非大段字幕呈现。

**转场：** 视线从人物的目光退回刚吃完的餐盘，桌和人物位置关系不变。

### 02｜12–24秒｜食物→消化→小肠吸收→血液

**首帧：** 餐桌上的淀粉类食物已明确是来源。画面的“局部注意力放大”从盘子进入体内的简化消化视图。

**连续机制：**
1. 一小段抽象淀粉链随“消化”操作分成葡萄糖符号，其他养分仍保留背景，不声称所有食物都是葡萄糖；
2. 一次清晰尺度进入：从食物转到躯干透明人体的**胃肠轮廓**，小肠用位置和短标签指认；
3. 葡萄糖在小肠处**吸收进入血液**，简化流向肝脏的门静脉路径（可视需要缩略，不虚构直通腿部的瞬移）；镜头停留让观众辨清“肠道”和“血液”不是同一结构。

**科学限定：** 不在胃部直接画“葡萄糖被胃壁吸入血管”；只在画面关键位置写“消化”“小肠吸收”“进入血液”。

**转场：** 一条血液运输路径从躯干半透明图延伸出来，人物继续走路的鞋底落地声在画外自然响起，将镜头带回宏观行为。

### 03｜24–36秒｜整个人行走，多处骨骼肌参与

**首帧：** 不是旧技术样片的几何小人。角色站姿合理，头-颈-肩-腰-骨盆-双腿连接和双脚掌触地清楚。

**连续事件：** 起步、行走数步、摆臂；身体重心自然从一条支撑腿转移到另一条，臀部保持骨盆稳定，躯干做轻微旋转和平衡动作。

**全身运动透视：** 角色外观线条短暂转为半透明，多个骨骼肌群依次被轻微标亮：下肢与臀部明显、躯干适度、摆臂相关上肢轻微。**亮度与活动不完全相同、不同步、不将所有肌群画成同幅收缩**。

**镜头：** 由人物中景环绕少量角度进入全身半透明图，侧面/三分之二视角必须保持腿、手臂、躯干可辨。不要因程序方便变成平面人体结构标签墙。

**视觉主句：** “不是只剩腿在工作，而是多处骨骼肌以不同方式参与走路。”

**转场：** 全身人体轮廓保持为下一镜头的主视觉锚点，不能从某一条腿硬切出独立科学图。

### 04｜36–49秒｜透明人体里的运输和调节：器官有不同职责

**首帧：** 上镜头全身人物的半透明轮廓还在走路，体内可见循环、胃肠及少量肌群的概括性层次。

**事件与注意力分配：**
1. 消化道和小肠区域轻亮，已吸收的葡萄糖符号在血液路径上出现；
2. 血液循环亮起几条典型运输路径，先经过肝脏相关区域，再分布到活动中的骨骼肌等组织；**简化示意不等于所有分子走完全相同单一路线**；
3. 肝脏用“调节/储存与供给”简短提示，胰腺与胰岛素的调节以轻量辅助标识出现，背景心脏搏动为循环提供节奏，但本集不进入心脏细胞摄糖机制；
4. 不同骨骼肌活动区出现**有节奏但不同时爆发**的信号；避免全身肌肉普遍瞬时“吸糖发光”。

**镜头：** 先展示完整人体让观众定位器官，再一次只放大一个区域。可借一条血液路径移动主视觉注意力，再缩回整体。不能为了酷炫在14秒里连续切换六次器官。

**主要内容：** 观众知道葡萄糖通过血液输送，各系统扮演不同角色；无须学会肝糖原或激素分泌的详细化学机制。

**转场：** 在全身肌群高亮中，**选择臀部外侧的一处正在活动的骨骼肌**（也可以由工程验证后改为躯干/腿部的一处明确骨骼肌，须在导演稿中固定，不得无解释漂移）。重点是这一处代表性肌肉既属于整个人的运动，又能通过统一空间锚点继续放大。

### 05｜49–67秒｜从完整人体进入代表性肌群/细胞：本片微观主场

**观众空间路径：** 全身半透明人 → 臀部外侧具体骨骼肌 → 肌肉组织/肌束 → 毛细血管与组织间隙 → 肌细胞膜 → 细胞内。

**具体可执行的连续动作：**
1. 镜头围绕活动骨骼肌的固定空间锚点推进；全身其他区域渐隐，**该肌肉与骨盆相对位置持续可见**。
2. 肌束在动作中呈细微收缩/舒张状态；内部小血管逐步出现，新增细节随倍率逐层解锁，**不允许放大旧人体PNG**。
3. 放大到一段血管：一个黄色符号从**毛细血管内部**出现，越过标识清楚的**血管壁**；第一次空间停顿让观众确认它已经进入**组织间隙**。
4. 继续向右移动到**肌细胞膜**。镜头仅保留当前两道边界和高亮粒子的运动；在细胞膜示意转运入口处，葡萄糖进入细胞内部。
5. 细胞内部只显示适度的代谢活动/储存提示，不画成必然立即“燃烧光效”；适度显示膜上的转运机制与肌肉收缩有关，但不强制在口播中说 GLUT4。
6. 小字提醒“原理示意，时间与尺度已压缩”，必须在手机上能读到，但不能干扰主动作。

**科学底线：** 不让每一步落脚触发一颗葡萄糖；不把肝脏、心脏、肠道全部画成同一种骨骼肌GLUT4转运示意；不把微观粒子数量当成血糖浓度。

**镜头重点：** 这是一次真正的“走进身体内部”，镜头推进越深，结构越精细；退出时还要走相反路线。非必要时不能在细胞上再插入多次毫无解释的新视角。

### 06｜67–80秒｜由细胞退出全身：把科学机制与人的行动重新接起来

**首帧：** 接续上一个细胞图，适度停留，然后跟随同一空间锚点反向退回肌束→臀部/骨盆→半透明人体→完整衣着人物。

**视听因果：** 画面上先还原人体正在迈步的骨盆与躯干，再见全身稳定步态；旁白重申肌肉活动促进葡萄糖摄取，**不是走一步血糖瞬时跳降**。

**可显示的结果关系：** 幕内将“肌肉工作”与“葡萄糖可以进入肌细胞”置于同一连贯空间，不能以“血糖数字一秒从9降到5”作为结论。

**摄影：** 缩回全景比推进略慢或相当，既要自然，还要让观众看出“刚才看到的是这个人的体内”。人物从未换成第二个人，衣服/行进方向不变。

**转场：** 一条行走路径连到纸页边缘，翻出“短期研究”的独立研究页，**不让黄色葡萄糖变成伪造统计数据点**。

### 07｜80–99秒｜真实研究是怎样的：短期平均方向，不是寿命承诺

**首帧：** 类似研究者的手绘纸页，不需要大量公式和图标。

**三次揭示：**
1. 八张标号简洁的便签逐一汇聚，字幕“8项短期试验”，不为每项编造数字；
2. 画面将“饭后不运动”和“饭后运动”分别置于左右两个简洁人物小场景，坐着与活动的姿态清楚，字幕不超过必要内容；
3. 便签汇总成一个简洁的定性结论：“餐后血糖波动：总体较小”，角落注明“研究汇总示意，非个体记录”。

**注意**：不能画出未经来源支持的“平均血糖两条真实曲线”；不能说8项全部是步行，也不能证明“九十九”。研究质量有高偏倚风险，口播用“总体”“人和人效果不同”提示边界即可。

**摄影**：便签聚拢和条件对照有实际动作，结论出现后留足一次手机阅读时间，不靠来回无意义缩放。

**转场**：研究卡回到人物路径旁，故事仍在那个人身上，不结束在陌生的数据大屏。

### 08｜99–116秒｜同一个人继续走，回到俗语的合理含义

**首帧：** 开场同一个人物仍在日常环境中走路。镜头从远处回到全身中景，然后稍稍拉远，人物脚步不断。

**反向空间呼应**：上一场的小研究卡被收回，身体半透明只出现极短一瞬，提示“身体内的过程仍在发生”，随即恢复完整人物外观。

**落点**：一句手写“量力而行，规律活动”随行走路径出现；“活到九十九”只保留文化意象，不变成寿命统计图。

**音画收束**：脚步声渐远、手绘笔触落下，片尾不用定格卡强拖时长；观众应记得“走路不保证长寿，但确实有可理解的生理机制与短期研究支持”。

## 3. 与用户强调的“局部放大—缩回”一致的三条可验收条件

1. **空间位置可追踪**：至少有一个关键进/出镜头中，观众不看字幕也能指出“这块细胞图来自整个人的哪块肌肉/身体区域”，并在回缩后认回原人物。
2. **尺度改变同时出现新内容**：全身、器官、组织、细胞四级之间，要有相应结构及运动状态揭示，不得只是对同一图无穷缩放。
3. **叙事因果优先**：放大不是炫技，必须解决观众当下困惑；收回后必须把新信息归还给日常行为。

## 4. 视觉与科学技术限制

- 人物美术先按 `CHARACTER_AND_CAMERA.md` 规范制作：真实可辨头肩腰骨盆手臂/腿脚，具有自然体积与动作；**旧样片抽象角色不能直接复用**。
- 画面信息层级：同时只突出一个问题；小字术语最多一两个焦点标签，所有学术证据不得通过堆积小字强塞进手机。
- 全片禁止没有来源的血糖真实数值、虚构人体透明拍摄特效、视频里“一迈步立即被吸走一颗血糖”假因果。
- 胰岛素、肝脏、胃肠、骨骼肌与循环系统是不同角色；全身透视不得把所有器官画成同一种肌肉摄糖机器。
- 同一 Sketchbook 风格不代表所有事物必须 Q 版；角色应有正常人比例，科学结构有适当写意简化。
- 同一剧情镜头可以适当静止以给观众阅读，但不能是静态图轮播/随机图形漂移冒充动画。
- 不能用技术 `deterministic:true`、测试全绿或读到了所有参考文件来直接证明镜头审美达到90分。

## 5. 独立内容审核应提出的问题

- 开头是否既有可信人物和钩子、又不会诱导寿命错误理解？
- 是否清楚显示“消化吸收入血”且人体器官空间合理？
- 是否把“多肌群活动”画得有不同参与强度，而非宣称全身所有细胞同时吸糖？
- 全身透视是否可看懂；观众跟得上从肠道到骨骼肌再回到人物吗？
- 细胞机制是否区别血管壁、组织间隙、肌细胞膜？是否暗示虚假即时因果？
- 研究段落是否遵守“8项短期、不同运动形式、仅汇总方向”？
- 完整自然语速可否真正在<120秒内听明白、看明白？不允许口播和视觉同时过载。
- **不能仅凭文字阶段评分想象实际画面好。** 正片完成后必须有真正的独立观看验收，但文字稿现在应先明确执行路径与信息优先级。
