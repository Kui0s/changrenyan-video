# EP01 v2.1｜全身生理机制证据与画面边界（送独立审核）

> **创作端已检索来源，独立科学核查尚未完成。** 本文解释哪些可展示、哪些会造成机制误导。不可凭动画美观替代科学准确性。

## 1. 从消化到血液：不是米饭直接进入血管

- NIDDK（美国国立糖尿病、消化和肾脏疾病研究所）《Your Digestive System & How it Works》：https://www.niddk.nih.gov/health-information/digestive-diseases/digestive-system-how-it-works
- 食物中的碳水化合物在消化中被分解为单糖，小肠吸收后进入血液；吸收营养经门静脉流向肝脏等器官，肝脏参与营养处理、储存和释放。
- **允许**：全人体局部透视 → 胃肠道/小肠 → 吸收 → 血液运输；用简单淀粉链分解成葡萄糖示意。
- **禁止**：整粒米饭直接穿进腿部血管；不经肠道/血液就被肌肉细胞吸收；将胃作为葡萄糖主要入血吸收位置。

## 2. 从全身活动到肌肉摄取：多肌群参与，但不等同强度

- Richter, Bilan, Klip（2025），*Physiological Reviews*：https://pubmed.ncbi.nlm.nih.gov/40173020/；全文 https://journals.physiology.org/doi/full/10.1152/physrev.00033.2024
- 运动中的骨骼肌可加强葡萄糖摄取；葡萄糖经过毛细血管壁、组织间隙、肌细胞膜。骨骼肌细胞膜上的 GLUT4 等转运机制受收缩与胰岛素相关信号调节；肌细胞内葡萄糖可参与能量代谢或储为糖原。
- 正常步行不是仅一条腿工作：下肢主要推动/支撑，臀部与躯干参与稳定及动力协调，上肢有不同程度的肌肉参与，但不能画成全身所有肌肉以同样强度收缩。相关上肢步态肌电研究：https://pubmed.ncbi.nlm.nih.gov/21945656/；臂摆和下肢协调：https://pmc.ncbi.nlm.nih.gov/articles/PMC8252748/
- **允许**：全身半透明肌肉层，腿/臀较显著、躯干较轻、摆臂更弱的不同程度运动提示；选择一处正在活动的**骨骼肌**代表性放大，解释两个不同生理边界；保持人物空间身份。
- **禁止**：将心肌、肝脏、胰腺、肠道等全部渲染为同一 GLUT4 骨骼肌收缩机制；把每次脚落地绑定一颗葡萄糖即时过膜；把葡萄糖全部画成立刻燃烧。
- 如画胰岛素/胰腺：只作为进餐后调节葡萄糖利用的辅助层，不把复杂激素过程讲成随步态启动/关闭的简单开关。
- 如画肝脏：展示“调节/储存/供给”的中性角色，不用“肝脏必然瞬间把血糖拉低”的虚假因果。

## 3. 餐后活动对短期血糖的实证

- Engeroff, Groneberg, Wilke（2023），*Sports Medicine*：https://pubmed.ncbi.nlm.nih.gov/36715875/；开放全文 https://pmc.ncbi.nlm.nih.gov/articles/PMC10036272/
- 8项随机交叉试验、30干预条件、116人（含不同糖尿病状态）、**存在较高偏倚风险**。比较饭后运动、饭前运动与不运动条件；汇总方向为饭后运动相对于不运动有更小的**短期餐后血糖波动**。部分条件是步行，但不能将所有干预说成步行。
- **允许**：8张小研究卡汇总→“饭后运动 vs 不运动”→“短期总体波动较小”；明确“研究汇总示意，非真实个体曲线”。
- **禁止**：造出两条看似实测的平均血糖时间序列；添加真实论文中未提供的单项试验数值、每分钟变化或精确有效步数；把该研究当成长期死亡率试验。

## 4. 长期健康与“九十九”

- WHO 身体活动事实清单：https://www.who.int/news-room/fact-sheets/detail/physical-activity
- 规律身体活动有广泛健康益处；长期健康证据与上面的**短期餐后血糖实验**不是同一种结论。
- “活到九十九”作为俗语表达健康长寿，不能画成实际可兑现寿命。
- 避免具体人群的运动时间/强度医学处方；身体状况、用药和运动能力不同，温和建议“适合自己、循序渐进、规律活动”。

## 5. 全身透视的科学规则

1. **透视不是在真实时间里同步直播所有细胞**：视图使用压缩时空的示意，必要处标“原理示意 / 非实时测量”。
2. **统一人体坐标**：消化道与小肠在躯干内正确的相对位置；血流连接全身但必须避免把肝脏直接省略成零处理的“透明管道”。
3. **不同系统不同画法**：循环系统用于运输，消化用于分解/吸收，骨骼肌用于收缩/摄取，肝脏和激素调节只作辅助。不要让所有系统共用同一种放大粒子动画。
4. **只给观众看一条主线**：正片最多深入一处代表性骨骼肌细胞示意，其他肌群在全身透视中显示相似的活动参与但不复制整屏细胞视图。
5. **放大有真实层次**：全身→肌肉区域→毛细血管/组织间隙→肌细胞膜→细胞内，返回时沿相反路径收回。
