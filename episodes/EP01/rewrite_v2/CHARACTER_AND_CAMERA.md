# 《常人言》EP01 v2｜完整人物、全身透视与多尺度镜头视觉契约

> **创作草案，待独立内容审核。** 用户不接受原先像“头+长条躯干+几根断接线腿”的技术样片人物；本新方案必须先在**完整正片**中采用自然且可识别的成人角色，而不是仅满足关节坐标的测试人物。

## 1. 人物外观：让人第一眼看出是正常的人

- 普通成年人，日常衣着（上衣、裤子、鞋），姿态自然，不以性别/年龄刻板视觉符号为主。
- 头、脖子、肩、胸腔、腰、骨盆、上臂/前臂/手、左右大腿/膝/小腿/脚掌有连贯形态。衣服有完整包裹与运动褶皱；不出现悬浮肩膀、腿从肚子外侧挂下、手臂交叉穿透身体。
- 可以是简化手绘动画人，但不能借“Sketchbook抽象美学”掩盖人体连接错误；腿脚应画出真实步态中的受力、抬腿、落脚与重心转移。
- 从片头餐桌、全身走路、透视回退到结尾同一角色，不得形态比例突变、换衣或左右手脚身份互换。
- 表情细节不必写实，但应对“九十九？”的怀疑有可辨识的眼神/微笑/动作反应。不要为了审美一味Q版；自然好看且匹配故事即可。

## 2. 全身半透明不是“器官列表”

### 宏观透视层

将同一人物由正常皮肤/服饰逐步变成简化的**人体半透明多系统视图**，保留外形轮廓与姿态。观众需持续认出这是刚刚走路的人。

- **消化层**：胃部和小肠位置相对正确；营养吸收重点在小肠，不把胃作为主要葡萄糖吸收场所。
- **循环层**：心脏泵血节律与血管大致回路，用适量动线提示运输；不画成只要一吃饭全身血管就同时闪烁。
- **调节层**：肝脏与胰腺/胰岛素若出现，服务“身体处理葡萄糖”的背景知识；不让它们重复骨骼肌细胞同一个转运动画。避免大篇幅标注。
- **肌肉层**：在行走动作中，腿与臀部明显、躯干参与稳定、摆臂相关上肢轻微呈现运动参与的差异。不同肌群可不同程度收缩/变形/明暗变化，不能全身所有肌肉同幅同节奏地发亮。
- **信息焦点**：每一时刻只强调当前旁白对应的一个器官/变化，其他图层降亮但保留空间定位。整体像一个可理解的人，不像医学软件的密集器官控制面板。

### 微观结构层

完整人体中选择一个**明确可追踪的骨骼肌局部（建议臀部外侧活动肌群）**作为机制深入点，不说明“只有这里发生机制”，也不在全片复制几十个相同细胞动画。

放大后的层级分别为：
`全身肌群定位 → 具体骨骼肌局部 → 肌束/毛细血管 → 血管壁 → 组织间隙 → 肌细胞膜及转运通道 → 肌细胞内`。

每进入一层必须真正生成该层需要的结构和动态：不能只对同一张图持续拉近，也不能突然把人体切换到两个毫无空间关系的长方形框。

## 3. “推近—揭示—退出”的镜头算法与导演契约

### A. 整体到局部

1. 相机从步行角色的**世界坐标**开始，平移并缩小视野；人物仍在真实行走。
2. 选定的骨骼肌部位随角色运动保持锚点（例如臀部外侧肌群与骨盆固定相对位置），出场时给一瞬自然高亮。
3. 使用渐进尺度场景切换：外部衣着与皮肤逐步打开一个连在身体上的示意窗口，里面才出现肌束、血管、细胞，不能只用无关场景的透明层叠加蒙混过去。
4. 放大途中需要有逐层新增的可见结构与状态，调速要让观众看出这是**同一个人的某个部位**，不是动画模板被直接替换成一张科普图。

### B. 局部到微观

- 只跟踪一条葡萄糖示意路线，让观众跟得上“血液→血管壁→组织间隙→细胞膜→细胞内”；不同边界有清楚、但不过度复杂的结构形象。
- 同时可以出现肌细胞周期性形变或局部收缩符号，突出“肌肉正在活动”，不可机械同步成每迈步就摄入一颗分子。
- 光斑、线条和文字服务于主要动作。无证据不能画真实血糖实时值或快速降糖仪表盘。

### C. 微观到整体

- 同一个相机锚点反向回到肌束→具体骨骼肌→全身肌肉层→正常衣着人物。
- 返回时人物**依然在走路**，行进方向、鞋服和背景一致。
- 观众不看文字也应能回答“刚才那段细胞动画是在这个人的哪个部位”。
- 不要求逐帧使用数学严格可逆的同一相机投影，但至少保持空间语义连续。不要突然硬切到另一位陌生人物。

### D. 什么时候用局部放大

- 只对重要机制、关键生理边界、决定观众理解的部位采用明显推进。
- 对研究结果可改用纸面卡片的聚合/对照，**不重复人体推拉镜头**。
- 对消化吸收可使用一次较轻的局部推进；对骨骼肌内部机制进行本片最完整的多尺度穿越；对结尾进行完整回缩。
- 有意义的短暂停顿允许，随机抖动/旋转不等于运动叙事。

## 4. 2D实现可行，但必须有分层空间与动作真实性

- 可以使用上游 MIT Sketchbook 引擎（`cth9191/animate` 固定commit），不要求再另造3D引擎，也不必逐器官还原真实医学扫描。
- 允许 2D/2.5D骨骼、分层蒙版、摄像机变换与可见组织形变组合；**视觉验收以最终效果为准**，不能因为程序没有采用3D就否定，也不能因为用了真实技术就给高分。
- 相关结构要随时间函数真实变化，支持抽帧与连续播放；程序化原创角色/场景不得照搬上游灯泡变太阳等原有场景。
- 字幕用不夸张的大字号引导注意；中文自然配音与关键动作同步；避免同时出现4个以上专业术语的密集阅读画面。

## 5. 观众可理解性与角色验收

- 第一帧：不读文档，正常观众是否认出一个自然的人，而不是几何杆件或拼接机器？
- 走路3秒：能否看到真实站立承重、步态与上肢协调，而不是躯干悬浮剪刀腿？
- 全身透视：能否区分“消化”“血液运输”“肌肉工作”各自角色，并能看出多个肌群参与程度不同？
- 微观推进：能否从人体整体追踪到指定肌群，理解为何进入这处细胞？
- 回退：能否一眼认回同一个人并记住“体内过程与走路有关”？
- 完整看完：观众能否回答老话的正确科学边界，而不是只记得一串闪亮器官和黄色点？
- 若以上失败，原有 `S`/ `C`/ `V`/ `M` 维即应如实反映，**不能因测试绿灯而自动给出≥4.5分**。
