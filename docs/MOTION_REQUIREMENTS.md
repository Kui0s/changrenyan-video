# 动画导演与连续性工程约束 v1.0｜防止幻灯片化

## 核心判断

**视频是关于时间中发生的变化，不是把N张静帧编码成MP4。** 帧率、1080×1920尺寸、字幕齐全和画风好看，只能说明媒体文件存在，不足以证明完成动画导演。

本项目将视觉运动分三类：

- **叙事性/因果运动**：人物行动、物体发生状态变化、机制的过程被展现；这类运动是关键内容的主要承载者。
- **摄影运动**：镜头追随角色、改变视角、进入物体内部、连接两个空间；摄影运动应有叙事动机。
- **辅助运动**：文字出现、线条微动、背景粒子、装饰性放大；不能用这类运动替代前两类。

静止并不天然不合格。科学结论、读图或情绪停顿可以有意识地留住关键画面；必须在导演稿注明目的和预期观看时间。

## 每个镜头都需要的制作契约

1. **动作主体**：具体角色/对象及在场景中的唯一身份。
2. **起点/终点**：进入镜头时与离开镜头时的可观测状态（位置、姿态、材质、数值、结构）。
3. **连续动作轨迹**：至少描述关键变化之间的中间行为；人物动作需骨架/关节或其他连续动画方法，不得直接跨两张 pose 跳切。
4. **摄影轨迹**：画面景别、镜头位置、世界到屏幕的统一变换关系；主体运动与相机运动不能相互失配。
5. **信息揭示顺序**：观众应先看到什么、再理解什么；重要动作与旁白词语/音效/字幕如何对齐。
6. **衔接点**：下一镜头复用什么物体、动作方向、形状或音效作过渡，或者为什么要明确硬切。
7. **证据与红线**：如果是科学示意，列需要正确呈现的物理/生理边界。

## Codex 技术实现建议（不限定唯一技术栈）

- 将画面定义为 `renderAt(t)` 或等效的时间函数，支持独立跳转到任意时间点；必要随机性使用固定种子。
- 为角色、肌肉、葡萄糖粒子、相机等建立连续随时间变化的状态函数，不要每个场景只用1张固定画布。
- 场景之间可使用 shape morph、camera tracking、match cut、camera pan、parallax、handwritten paths 等已验证代码技法，不能只因为有工具就堆叠全部动效。
- 开发时先在当前风格的原 demo 上扩展角色/相机/机制动画，禁止另起无关绘图库然后以截图相似度宣称保持风格。
- 保留真实镜头级轨迹、画面事件与音频 cue 的可复核文件或源码入口，不能仅提供最终导出视频。

## 非幻灯片式验收（工程和内容两侧都检查）

1. 为每个镜头输出起点/中段/终点及关键动作0.2–0.5秒抽帧联系表，**实际检查角色姿态与对象位置发生了合乎目的的连续变化**。
2. 逐段观看真实成片，问：去掉字幕后，关键动作或科学机制是否仍可理解？如果只有标签/配音动，核心对象不动，属于高优先级缺陷。
3. 对每个主要镜头记录至少一个可以描述的“事件”——例如迈步导致腿部收缩、镜头进入腿部、葡萄糖经过转运边界——而不是仅有“背景缩放”。
4. 自动脚本可测连续相近帧的差异、空帧、丢帧和停滞区间，但**帧差异不等于有效动画**：色彩噪点、颗粒抖动、字幕滚动都能制造帧差，所以必须有人看完整动作与因果。
5. 未经导演注明的多秒核心画面冻结，需要返工诊断；不强制所有帧每时每刻变化。
6. 对连续动作检查骨架拉伸、道具绑定、主体跟踪、遮挡关系、镜头平移和速度突变。发现不连贯需定位具体时间码。
7. 全片编辑阶段核查场景之间的空间/时间逻辑，避免“5秒画面A + 5秒画面B + 5秒画面C”的照片幻灯片结构。
