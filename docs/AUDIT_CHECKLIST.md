# 可迭代审核检查表 v1.0｜不改变评分尺度

此文件是 `SCORE_RUBRIC.md` 的**检测工具**，不是第二套评分规则。发现新的缺陷后可以增加测试用例，但不可偷偷改变七个维度权重、90分门槛或用“更适合现有作品”作为降低质量的理由。

## 研究/导演稿阶段（独立 GPT）

- [ ] 俗语隐喻含义正确（九十九 = 健康长寿的代称）
- [ ] 观点逐项有来源，区分随机短期试验、人体机制和长期相关性
- [ ] 任何无证据的因果都没有被断言为确定事实
- [ ] 一分钟口播按实际试读/合成声音测时，时长与停顿真实可实现
- [ ] 每个镜头明确动作主体、初始/终止状态、相机路径、转场和旁白的对应时机
- [ ] 每个镜头在真实时间内能够被普通手机观众看懂
- [ ] 不把主叙事交给字幕说明，不以技术噱头替代内容解释

## 15秒样片（独立 GPT + 独立 Codex）

- [ ] 真实源风格 `kit.js`、公共引擎、Demo 已成功复现
- [ ] 新角色与绘图沿用已确认风格的代码组件，而非凭图片临摹
- [ ] 人物迈步包括腿部交替、关节过渡及合理的身体重心变化
- [ ] 相机追随主体并保持空间连续性，不是单纯把一张人体图放大
- [ ] 实际存在连续的生理机制变化：血液→组织间隙→肌细胞的示意路径
- [ ] 关键动作有实际多个中间状态；提供0.2–0.5秒间隔抽帧或视频供核验
- [ ] 无连续多秒无叙事理由的停滞；有意识的静帧用于理解是允许的
- [ ] 配音、字幕、音效对应动作事件，不发生明显错位
- [ ] 实际 MP4 与完整源码对应，并能重复渲染
- [ ] 第三方代码、声音、字体使用权限均有记录

## 完整视频

- [ ] 每个镜头对全片论点有明确作用
- [ ] 开头是事件/问题的动态展开，非纯标题封面停留
- [ ] 中段因果过程可以在不看大量字幕的情况下理解
- [ ] 转场追踪真实视觉对象，不靠一连串随机淡入淡出
- [ ] 画面、旁白、音乐有合理的张弛与暂停
- [ ] 同一角色和图示在不同场景中造型与符号一致
- [ ] 示意图有“原理示意/非实测”的必要标注，缺证据不出现虚构精确量化
- [ ] 最后的结论明确，不越过科学证据边界
- [ ] 90分固定尺度、单项底线、硬否决、最终用户同意均满足

## 迭代规则

新增检查项必须记录：版本、发现的问题、时间码/截图/数据、所属原评分维度、适用场景与审核方法。禁止增添与原评分目标无关的指标来强迫某一种风格、运镜或转场手法。对于已完成的历史审核，保留当时结论；必要时另开复评文件并说明新的检查证据。
