## 1. 用户明确决定

- **正式成片在2分钟以内（不超过120秒）**。此前的60–68秒仅保留为已有导演时间轴的**示意起点**，不作为固定目标或单镜时码硬约束。
- 正式中文声音可在**后期剪辑时**选用剪映等编辑器提供的 AI 朗读，也可由用户本人录制。默认按自然正常语速表达；**不预先指定精确的字/秒或词/分钟**。
- 当下不能验证正式声音，不要求为了审过文字导演稿，提前提供普通话音频、声音哈希、逐句语音时间码、真实字幕同步报告。
- 镜头长短由科学信息量、动作自然完成时间和读图需要决定；允许留白，但不能用无意义长静帧来拖时长。
- 未来实际成片出现声音后，**仍须**检查发音可理解性、自然断句、语速、字幕可读性、声音与动作/画面同步、成片时长与版权；不能将“此刻不验”写成“音频已通过”。

## 2. 按阶段划分必需证据

| 阶段 | 本阶段必须审核 | 本阶段不应强制的证据 |
|---|---|---|
| **文字研究 / 旁白 / 导演稿** | 科学论据与边界、口播可理解性、镜头动作与因果、观众一次观看的说明逻辑、计划中时长可合理控制在120秒内 | **尚未制作的正式配音、逐句实测音轨、最终字幕同步**；评分 A 作为该阶段 **N/A（阶段范围外）**，而非 N/V |
| **原创15秒技术样片** | 真正的新动作、源风格/连续镜头、科学结构、源码diff、MP4和工程复现；若提交语音/字幕则审核其已有质量和一致性 | 不强制提前选定最终剪映声音或用户亲自录音；可无音轨或使用清楚标记的临时占位声音；最终成片才强制正式音轨 |
| **正式全片 / 剪辑成片** | 画面科学、动作、画风、技术、**正式中文配音、字幕同步、音乐/素材授权、完整音画及≤120秒**；七维完整评分、双独立审核与用户批准 | 不得用文字稿上的估算时长或低保真 eSpeak 结果代替真正成片的音画验证 |

> `SCORE_RUBRIC.md v1.0` 明确允许按阶段将**未进入该阶段的维度**标为 N/A；但已进入该阶段且要求交付的证据若缺失，仍须 N/V。正式成片的 A 维不能因为此政策被排除。所有实际适用维度按固定权重归一化计算，阶段通过线仍是 ≥90/100、适用维度 ≥3.5/5、无硬否决。

- 用户最终放行15秒原创样片、进一步全片制作与正式发布的决定权不变。

## 4. 制作端执行方式

1. 导演稿保留一个**相对时序**（例如步行→肠道吸收→肌细胞摄糖→研究比较→边界与结尾），镜头秒数写作暂定，可按自然叙事增加或缩短。
2. Codex 生成的动画尽可能使关键动作时长可参数化，预留字幕/口播 cue 的调整空间，避免根据 eSpeak 63.9秒实验将所有画面锁死。
3. 到剪辑阶段再依据实际选定声音进行断句、镜头伸缩、字幕配对和总长校验；有必要时修改解说文本，保持科学意思和视觉因果不变。
4. 每个阶段只提交本阶段实际存在的证据，不能声称尚不存在的音频、成片或原创样片已通过。
